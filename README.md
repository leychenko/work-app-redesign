# Work Finance

Адаптивна фінансова панель на Vue 3. Вона зберігає функції початкового проєкту:

- декларації та пошук товарів;
- фінансові записи, зарплата, денні й нічні бонуси;
- податки за місяць і квартал;
- акти, пошук за періодом і номером, редагування;
- графік доходу, курси валют і погода.

## Запуск

    npm install
    npm run serve

## Збірка

    npm run build

## Налаштування Firebase

Перед запуском додайте до локального файлу .env.local свої значення:

    VUE_APP_FIREBASE_API_KEY=
    VUE_APP_FIREBASE_AUTH_DOMAIN=
    VUE_APP_FIREBASE_PROJECT_ID=
    VUE_APP_FIREBASE_STORAGE_BUCKET=
    VUE_APP_FIREBASE_MESSAGE_SENDER_ID=
    VUE_APP_FIREBASE_APP_ID=
